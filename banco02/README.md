# 🏦 Sistema Bancário Completo (Python)

Bem-vindo ao nosso sistema bancário  #Python! 🐍

Este projeto foi refatorado e expandido para oferecer uma experiência bancária mais completa, agora com gerenciamento de **usuários** e **contas**.

---

## ✨ O que você pode fazer:

### 👤 Gerenciamento de Usuários e Contas:
* **Novo Usuário** `[nu]`: Crie seu perfil completo (CPF, nome, data de nascimento, endereço).
* **Nova Conta** `[nc]`: Abra uma conta bancária vinculada ao seu CPF.
* **Listar Contas** `[lc]`: Veja todas as contas cadastradas no sistema.

### 💰 Operações Financeiras:
* **Depositar** `[d]`: Coloque dinheiro na sua conta de forma fácil.
* **Sacar** `[s]`: Retire dinheiro, com limites de R$500 e 3 saques por dia.
* **Extrato** `[e]`: Consulte todas as suas transações e veja o saldo atual.

### 👋 E muito mais:
* **Sair** `[q]`: Feche o sistema a qualquer momento.

---

## 🚀 Como Colocar para Rodar:

1.  **Requisito:** Tenha Python 3 instalado.
2.  **Salve** o código como `banco.py`.
3.  **Abra o Terminal** na pasta onde salvou.
4.  **Execute:**
    ```bash
    python banco.py
    ```
5.  **Divirta-se!** Siga as opções do menu.
