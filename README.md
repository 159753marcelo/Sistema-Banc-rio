# 🏦 Sistema Bancário Simples

Bem-vindo ao nosso sistema bancário básico feito em Python! 🐍

Este projeto te permite:

* 💰 **Depositar:** Adicione dinheiro à sua conta.
* withdrawing_money: **Sacar:** Retire dinheiro, com limite de 3 saques diários e R$500 por saque.
* 📝 **Extrato:** Veja todas as suas transações e o saldo atual.
* 👋 **Sair:** Encerre o programa.

---

### 🚀 Como Usar

1.  **Salve** este código como `banco.py`.
2.  **Execute** no seu terminal:
    ```bash
    python banco.py
    ```
3.  **Escolha** uma opção no menu!
